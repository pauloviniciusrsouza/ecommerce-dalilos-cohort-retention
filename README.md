# ecommerce-dalilos-cohort-retention
Dashboard executivo de Análise de Cohort e LTV para o E-commerce Dalilos (~R$ 10.9M em receita e 7.2k clientes). Projeto end-to-end com prototipação no Excalidraw, modelagem/Views no PostgreSQL, validação no Google Sheets e visualização em Power BI (DAX/Star Schema).
